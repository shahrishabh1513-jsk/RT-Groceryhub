## ✨ About

**RT GroceryHub** is a modern grocery shopping website that makes online shopping smooth and easy. Fresh produce, pantry staples and artisan foods sit in one clean, mobile-friendly design, with a cart, a wishlist and a full checkout flow. It is built with plain **HTML5, CSS3 and JavaScript**, so there is no framework, no build step and nothing to install.

## ⚙️ Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/shahrishabh1513-jsk/RT-Groceryhub.git

# 2. Open the project folder
cd RT-Groceryhub

# 3. Run a local server (or simply open index.html)
python -m http.server 5500
```

Then visit **http://localhost:5500** 🎉  
Tip: in VS Code you can also use the **Live Server** extension → *Go Live*.
